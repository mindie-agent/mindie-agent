## 1. Native Google Antigravity Plugin (`mindie-agent-agy v0.1.0`) & 7-Component Adaptation

`mindie-agent-agy` ships a native Antigravity plugin bundle (`plugins/mindie-agent/`) aligned with all 7 shared runtime components:

1. **Native Lifecycle Hooks & Per-Conversation Knowledge Lease Gate**:
   - Ships `plugin.json`, plugin-root `hooks.json` (`SessionStart`, `PreInvocation`, `PreToolUse`, `Stop`), and `mcp_config.json` (`mindie-remote-dev`, `mindie-tools`);
   - Excludes all `knowledge_*` tools from public MCP discovery; typing `/mindie-agent` in a conversation triggers `PreInvocation` to issue a per-`conversationId` lease in `admission.sqlite3`, unlocking private `knowledge_cli.py` access to `mindie-knowledge` (subagents receive distinct `conversationId` values and never inherit parent leases).
2. **`remote-dev` Native Antigravity Tool Aliases**:
   - `mindie-remote-dev` exposes both canonical `remote-dev` tools (`remote_read`, `remote_write`, `remote_edit`, `remote_bash`, `remote_job`, etc.) and native Antigravity tool aliases (`remote_view_file`, `remote_view_file_outline`, `remote_view_code_item`, `remote_write_to_file`, `remote_replace_file_content`, `remote_multi_replace_file_content`, `remote_grep_search`, `remote_find_by_name`, `remote_list_dir`, `remote_run_command`, `remote_manage_task`) with bidirectional `StartLine`/`EndLine`, `WaitMsBeforeAsync`, and `Action` schema mapping.
3. **Full 7-Component `mindie-tools` Bridge & `AGY_CONVERSATION_ID` Propagation**:
   - `mindie-tools` exposes `mindie_status`, `diagnostics_status`, `diagnostics_bundle`, `coordinator`, `profiler`, `sim`, and `npu_top`;
   - `mcp_server.py` exports the verified `AGY_CONVERSATION_ID` to child tool invocations, and `mindie-coordinator` (`agent_session.py`) natively resolves `agy` / `antigravity` callers and `AGY_CONVERSATION_ID` for multi-session per-Die HBM leases and container bindings.
4. **Antigravity Brain Transcript Redaction & Capture**:
   - `agy_transcript.py` automatically promotes `<appDataDir>/brain/<conversationId>/.system_generated/logs/transcript.jsonl` to `transcript_full.jsonl` and strips `thinking`, `tool_calls`, and `<ADDITIONAL_METADATA>` wrappers before local deterministic (`r3`) + Gitleaks redaction.

## 2. Colloquial Prompt Suite & Full `G0–G5` Benchmark Results

Prior to running the `G0–G5` benchmark, Codex audited the `mindie-bench` harness to eliminate evaluation distortion (fixing cross-task flywheel store propagation in `native_product.py`, host `PYTHONPATH` leakage in `verifier.py`, container command routing in `ssh_shim.py`, and negative-control checks in `diagnostics`), and all 20 `tasks/zh-vague/` instructions were rewritten into realistic developer prompts (**1-sentence symptom + raw traceback or log path**).

1. **`G0 → G1 → G2` (48 L2 Trials + 18 Live L3 Ascend NPU Trials = 66 End-to-End Trials)**:
   - **L2 Suite (8 tasks × 2 models × 3 gears = 48 trials)**:
     - **DSH (`deepseek-flash`, `max`)**: `G0` `7/8 (87.5%)` → `G1` `7/8 (87.5%)` → **`G2` `8/8 (100.0%)`** (`G2` mean latency **`72.3s`** vs. `118.4s` on `G0`, **`1.64x` speedup**; complex Profiler attribution task converges in **19 calls / `68.5s`** on `G2` vs. 50-call budget exhaustion on `G0/G1`).
     - **Codex (`gpt-6.1-sol`, `xhigh`)**: `G0` `8/8 (100.0%)` → `G1` `8/8 (100.0%)` → **`G2` `8/8 (100.0%)`** (`G2` mean latency **`121.0s`** vs. `187.0s` on `G0`, **`1.55x` speedup**; complex Profiler attribution task drops from `513.5s` on `G0` to **`133.9s` on `G2`, `3.84x` speedup**).
   - **L3 Live Ascend NPU Suite (3 tasks × 2 models × 3 gears = 18 trials on A2 `173.125.1.2` `vllm-dev` 8×Ascend 910B)**:
     - Both DSH and Codex achieve **18/18 (`100%`)** pass rates across `G0 / G1 / G2`, with `G2` mean end-to-end latency dropping from `75.5s` to **`50.9s` (`1.48x` speedup)** on DSH and from `104.3s` to **`78.5s` (`1.33x` speedup)** on Codex.
2. **`G3` (Cross-Task Experience Flywheel: Seed `rotary_dim=64` → Stop Capture + C6 Distillation → Eval `rotary_dim=32` Black-Box `.so`)**:
   - On the black-box `.so` operator transfer task, both hosts fail (`0/2, 0%`) under `G0/G2` due to direct 32-dim slicing violating the `.so` ABI contract, and both pass (**`2/2, 100%`**, DSH `60.2s`, Codex `78.4s`) on `G3` after consuming the distilled `L2 SOP` unit.
3. **`G4` (`mode="explore"` RSI De-Biased Exploration vs. `G0/G2` Reuse Mode)**:
   - Across `dsv4-sparse-mla-qli-fusion-rsi-zh` and `triton-spatial-norm-dim-merge-rsi-zh`, both hosts jump from **`G0 (0/4, 0%) / G2 (0/4, 0%)` to `G4 (4/4, 100%)`**.
4. **`G5` (5-Episode Sequential Evolution Flywheel `Episode A → B → C → D → E`)**:
   - Codex (`gpt-6.1-sol`, `xhigh`) completes all 5 sequential episodes in a shared evolving workspace (`Episode A` SFA Cold Start `62.4s` → `Episode B` SFA Warm Reuse `50.5s`, `-19.1%` faster → `Episode C` Black-Box RoPE 64 Seed `113.0s` → `Episode D` Black-Box RoPE 32 Flywheel Reuse `113.4s` → `Episode E` Compound Multi-Fault Synthesis `70.2s`) with **`5/5 (100%)` pass rate**.
