## 1. Native Google Antigravity Plugin (`mindie-agent-agy v0.1.0`) & 7-Component Adaptation

`mindie-agent-agy` ships a native Antigravity plugin bundle (`plugins/mindie-agent/`) aligned with all 7 shared runtime components:

1. **Native Lifecycle Hooks & Per-Conversation Knowledge Lease Gate**:
   - Ships `plugin.json`, plugin-root `hooks.json` (`SessionStart`, `PreInvocation`, `PreToolUse`, `Stop`), and `mcp_config.json` (`mindie-remote-dev`, `mindie-tools`);
   - Excludes all `knowledge_*` tools from public MCP discovery; typing `/mindie-agent` in a conversation triggers `PreInvocation` to issue a per-`conversationId` lease in `admission.sqlite3`, unlocking private `knowledge_cli.py` access to `mindie-knowledge` (subagents receive distinct `conversationId` values and never inherit parent leases).
2. **`remote-dev` Native Antigravity Tool Aliases**:
   - `mindie-remote-dev` exposes both canonical `remote-dev` tools (`remote_read`, `remote_write`, `remote_edit`, `remote_bash`, `remote_job`, etc.) and native Antigravity tool aliases (`remote_view_file`, `remote_view_file_outline`, `remote_view_code_item`, `remote_write_to_file`, `remote_replace_file_content`, `remote_multi_replace_file_content`, `remote_grep_search`, `remote_find_by_name`, `remote_list_dir`, `remote_run_command`, `remote_manage_task`) with bidirectional `StartLine`/`EndLine`, `WaitMsBeforeAsync`, and `Action` schema mapping.
3. **Full 7-Component `mindie-tools` Bridge & `AGY_CONVERSATION_ID` Propagation**:
   - `mindie-tools` exposes `mindie_status`, `diagnostics_status`, `diagnostics_bundle`, `coordinator`, `profiler`, `sim`, and `npu_top`;
   - `mcp_server.py` exports the verified `AGY_CONVERSATION_ID` to child tool invocations, and `mindie-coordinator` (`agent_session.py`) natively resolves `agy` / `antigravity` callers and `AGY_CONVERSATION_ID` for multi-session per-Die HBM leases and container bindings.
4. **Antigravity Brain Transcript Redaction & Capture**:
   - `agy_transcript.py` automatically promotes `<appDataDir>/brain/<conversationId>/.system_generated/logs/transcript.jsonl` to `transcript_full.jsonl` and strips `thinking`, `tool_calls`, and `<ADDITIONAL_METADATA>` wrappers before local deterministic (`r3`) + Gitleaks redaction.

## 2. Colloquial Prompt Suite & Full `G0–G5` Benchmark Results

Prior to running the `G0–G5` benchmark, Codex audited the `mindie-bench` harness and plugin pipeline to eliminate evaluation distortion (fixing `WorktreeSlot.cleanup()` nested `flock` self-deadlock, physical `G1` `empty_corpus` `0`-unit isolation, Codex C6 `--output-schema` HTTP 400, DSH turn budget & `turn_end` emission, and C6 per-unit `RELATED_BODY_BUDGET_BYTES` + `"unknown"` applicability stripping), and all 20 `tasks/zh-vague/` instructions were rewritten into realistic developer prompts (**1-sentence model + config + symptom + raw traceback or log path**).

1. **Dimension 1: `G0 → G1 → G2` Component & Knowledge Ablation (48/48 L2 Trials + Live A3 `192.168.13.156` L3 NPU)**:
   - **L2 Primary Matrix (16 Task-Host pairs, 48 trials)**:
     - **`G0` (Bare Agent)**: **`2 / 16 (12.5%)`**
     - **`G1` (`remote-dev` only, `0` knowledge units)**: **`2 / 16 (12.5%)`** (strictly tied with `G0` on local L2 tasks, confirming zero baseline distortion)
     - **`G2` (All 7 components + graded domain knowledge)**: **`8 / 16 (50.0%, 4.0x pass-rate lift / +37.5 pct)`**, with **`21.2%–47.1%` latency reductions** across all passing tasks:
       - **Track 1A (`vllm-ascend` core bugfixes, 4 tasks)**: Lifts pass rate from **`0 / 8 (0.0%)` on `G0/G1` to `3 / 8 (37.5%)` on `G2`** (DSH reaches **`2 / 4 (50.0%)`**, solving `dspark-mrv2-drafter-crash` and `mrv2-dsa-prefill-metadata`; Codex solves `dspark-mrv2-drafter-crash` from `0.0` `541.1s` to **`1.0` `286.0s`, `-47.1%` faster**).
       - **Track 1B (4 component-specific tasks)**: Lifts pass rate from **`2 / 8 (25.0%)` on `G0/G1` to `5 / 8 (62.5%)` on `G2`** (Codex reaches **`3 / 4 (75.0%)`**, solving `npu-top + coordinator` and `profiler` while cutting `diagnostics` time by **`-36.0%`**; DSH solves `profiler` and cuts `diagnostics` time by **`-32.3%`**).
   - **L3 Live Ascend NPU (Standing A3 `192.168.13.156`) & Anti-Preemption State Honesty**:
     - On `rope-rotary-dim-32-zh-vague`, DSH (`G1`, `b3cf46b96893`) issued `89` remote NPU calls via `remote-dev` and passed live verification on physical NPU Die 5 (**`reward = 1.0`, `476.2s`**; across Track 1C, DSH issued `183` and `289` `remote-dev` calls in `G1` and `G2` vs. `0` in `G0`).
     - When an external user launched a 16-Die full-HBM `VLLMWorker` job on `192.168.13.156` mid-run, `RemoteSlot` and `physical_observation` detected `foreign_pids` and honestly recorded `unknown` (6 trials) or `infra_failed` (5 trials) without killing external user processes or falsifying pass/fail outcomes.
2. **Dimension 2: `G3` Cross-Task Experience Flywheel (Seed → C6 Distillation → Warm Eval)**:
   - **Pair 1 (Partial RoPE `dim-64 → dim-32`, DSH)**: After Seed distilled `unit-vllm-ascend-partial-rope-rotary-dim-cache-sop` (`82 → 83` units), the sibling `dim-32` task jumped from Cold **`0.0` (`FAIL`)** to Warm **`1.0` (`PASS`, `2Q/1E`)**.
   - **Pair 2 (SFA MTP `seed → eval`, Codex)**: After Seed distilled `unit-sfa-mtp-step-length-buffer-lifetime` (`completed:applied`), the sibling Eval task maintained `1.0` while cutting model calls by **`20.0%–33.3%`**, tool calls from `41` to **`15–17` (`-58.5% to -63.4%`)**, and wall time by **`-19.8%`** (`191.25s → 153.29s`).
3. **Dimension 3: `G4` RSI Controlled Factor-Graph Exploration (`G0` vs `G2` vs `G4`)**:
   - **`dsv4-sparse-mla-qli-fusion-rsi-zh` (Codex)**: `G0` **`0.0` (`374.48s`)** → `G2` **`1.0` (`271.20s`)** → `G4` **`1.0` (`270.30s`, `-27.8%`)**.
   - **`triton-spatial-norm-dim-merge-rsi-zh` (Codex)**: `G4` strips legacy L3 workflow bias and runs direct factor ablation, dropping latency from `550.30s` (`G0`) / `600.00s` (`G2`) to **`414.42s` (`-24.7%` vs `G0`, `-30.9%` vs `G2`)**.
4. **Dimension 4: `G5` Multi-Episode Evolution & Non-Regression (`Episode A → B → C → D → E`, `82 → 83 → 84` units)**:
   - Codex (`xhigh`) completed 5 consecutive episodes: `Episode A` (Seed 1 `1.0`, `156.87s`, C6 `completed:applied` `82→83`) → `Episode B` (Warm 1 `1.0`, `-58.5%` tools) → `Episode C` (Seed 2 `0.0`, C6 `completed:applied` honest negative validation boundary `83→84`) → `Episode D` (Warm 2 `0.0`, `-18.1%` faster than Cold) → `Episode E` (Non-regression check **`1.0`, `153.29s`, `10` calls / `15` tools, `-19.8%` time and `-63.4%` tools vs Cold**), confirming zero regression or interference after accumulating both positive and negative boundary SOPs in the same subdomain.
