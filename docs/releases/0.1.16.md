# 0.1.16：宿主插件大减法、零 Git 预编译自动更新、三档隐私解耦与 1:1 远端工具面

[English](0.1.16.en.md) · [产品组合](../../channels/0.1.json)

本补丁版本完成全栈产品体验升级与系统性工程减法：将全部 7 款原生宿主插件生产代码压降至 `<= 1,200` 行以内（净删约 7.8 万行重复业务代码，统一收敛至 `mindie-harness` 共享底座），交付零 Git 预编译 `mindie-wheels-bundle.tar.gz` 自动更新与单命令 `install.py` 安装入口，将 `gh` CLI 解耦为三档隐私模式（`contribute` / `local-only` / `read-only`），实现 `remote-dev` 全七端 1:1 原生镜像工具面与一步式静默 SSH 公钥接入（`remote_auth`），并在 `diagnostics` 与全部宿主暴露只读自检工具 `mindie_doctor`。

## 核心变更与验证

- **全七端薄宿主大减法（`<= 1,200` 行硬红线）**：`mindie-agent-codex v0.1.38`（`1,197` 行）、`mindie-agent-cc v0.1.30`（`1,125` 行）、`mindie-agent-kimi v0.1.31`（`1,062` 行）、`mindie-agent-dsh v0.1.26`（`1,134` 行）、`mindie-agent-agy v0.1.21`（`850` 行）、`mindie-agent-wb v0.1.19`（`1,111` 行）与 `mindie-agent-oc v0.1.11`（`1,057` 行）全面清退各自复制的更新器、GC、诊断包装与兼容垫片，委托 `harness v0.1.4` 统一承载，并由 `storage_lifecycle_gate.py` 永久拦截超标回潮。
- **零 Git 预编译自动更新与一键安装（修复 `#373` 等后台更新报错）**：`mindie-bench v0.4.14` 构建确定性 `mindie-wheels-bundle.tar.gz`（`< 16 MiB`，实测 `5.64 MiB`）与 `release-channel.json`；`harness v0.1.4` 使用 `SHA256SUMS` 流式校验、`--override` 零 Git 离线安装、`1h -> 6h` 指数退避且全程 `reportable=False`；顶层纯标准库 `install.py` 支持自动探测已装宿主并执行收据诚实（Receipt-Honest）安装。
- **`gh` 解耦三档隐私模式、1:1 远端原生工具面、`remote_auth` 静默配钥与 `mindie_doctor`**：`knowledge v0.13.24` 支持零 GitHub 账号的 `local-only` 本地脱敏沉淀（携带 `origin_tier="local-only"` 永不追溯外发）与匿名 HTTPS 语料同步；`remote-dev v0.11.14` 补齐 `agy`/`oc` 原生 1:1 工具面、支持一步式静默刷公钥与远端昇腾容器探测（高敏终端模式 `--password` 置尾）及 `r4` 密码脱敏；`diagnostics v0.5.17` 新增零副作用只读 `mindie_doctor`；全系 `SKILL.md` 固化“工具故障绝不阻塞任务连续性”铁律。
