# 0.1.13: Clean-Architecture Convergence, Shared `mindie-harness` Substrate & 7-Host Alignment

[中文](0.1.13.md) · [Product channel](../../channels/0.1.json)

This release completes the organization-wide clean-architecture refactoring and slimming across all 18 code repositories and 9 domain knowledge corpora. It extracts the shared cross-host substrate into `mindie-harness v0.1.0`—owning windowless subprocess & nested Win32 Job supervision, the deterministic cold-start Seed (`mindie-harness-seed.pyz`), `Active + Rollback` `.inuse`-leased atomic generation updates, the concurrent MCP gateway, and the single-state `ExperimentLedger` RSI loop—restoring `mindie-knowledge v0.13.23` exclusively to graded knowledge retrieval, two-layer redaction, and community distillation, while promoting `OpenCode v0.1.8` (`mindie-agent-oc`) into the unified 7-host product channel.

## Architecture convergence and validation

- **Standalone `mindie-harness v0.1.0` shared host substrate**: Consolidates cross-platform windowless process spawning and nested Win32 Job tree termination, offline-verifiable `mindie-harness-seed.pyz` bootstrapping, bounded two-generation (`Active + Rollback`, `<= 2`) runtime GC with `.inuse` leases and `.trash/` retirement (`P8`), and the single-state `ExperimentLedger` RSI optimization loop (`orient / propose / verdict`).
- **Zero pre-call session-binding gates on deterministic tools (`P2.7`) & receipt honesty (`P9 / P14`)**: All 7 native host plugins (`Codex v0.1.35`, `Claude Code v0.1.27`, `Kimi v0.1.28`, `DSH v0.1.23`, `Google Antigravity v0.1.18`, `Tencent WorkBuddy v0.1.16`, `OpenCode v0.1.8`) and shared components guarantee that standard MCP `tools/call` requests with zero `_meta`, zero prior hooks, and zero `request_nonce` execute all local single-user deterministic tools (`remote-dev`, `coordinator`, `profiler`, `sim`, `debugger`, `diagnostics`, `npu-top`) directly, reserving session/consent admission strictly for `knowledge_*` (`P2.1`) and `HostQueue` leases (`lease_id` + `fence_token`) for physical NPU/port exclusivity. Completed primary operations preserve `isError=False` with `receipt_warning` + `receipt_unconfirmed=True` if local SQLite accounting fails.
- **Full-stack alignment across 8 runtime components & `mindie-bench`**: `remote-dev v0.11.13`, `mindie-coordinator v0.7.13`, `mindie-profiler v0.5.16`, `mindie-sim v0.9.18`, `npu-top v0.3.5`, `mindie-diagnostics v0.5.16`, `mindie-debugger v0.1.4`, and `mindie-bench v0.4.11` enforce `< 800`-line core modules with top-30-line 4-section headers, single-entry `open_database` SQLite WAL + `busy_timeout=5000` initialization, `outer_timeout >= sum(inner_budgets) + cleanup_grace` timeout arithmetic, and zero-host-pollution Tier 0–3 test isolation.
- **Worktree-native hub routing, living bilingual docs & 8-profile CI gates**: `mindie-agent` establishes flat-sibling + `../.worktrees/<repo>-<topic>` contributor routing, archives superseded plans/reviews under `docs/archive/`, and enforces profile-specific PR checklists (`hub / harness / host-plugin / control-plane / state-service / device-tool / bench / corpus`) and focused AST anti-regression gates, alongside 506 graded units across all 9 `knowledge-*` public corpora.
- **Channel integrity & `R1–R6` verification**: All 17 components, host plugins, and the evaluation runner passed cross-platform CI (`ubuntu-latest`, `macos-latest`, `windows-latest`) and exact-source `publish-release.yml` benchmark gates; wheel/tarball artifacts, `SHA256SUMS`, `benchmark-manifest.json`, and all `R1–R6` automatic-update readiness checks passed verification.
