# 0.1.16: Host-Plugin Great Subtraction, Zero-Git Prebuilt Auto-Update, 3-Tier Privacy & 1:1 Remote Profiles

[中文](0.1.16.md) · [Product channel](../../channels/0.1.json)

This patch release delivers a product-wide UX overhaul paired with a Sim-style Great Subtraction: shrinking all 7 official native host plugins below `<= 1,200` production lines each (~78,000 duplicate lines removed onto the shared `mindie-harness` substrate), shipping zero-Git prebuilt `mindie-wheels-bundle.tar.gz` auto-updates and the single-command `install.py` entrypoint, decoupling `gh` CLI into 3 privacy tiers (`contribute` / `local-only` / `read-only`), enforcing strict 1:1 per-harness `remote-dev` tool surfaces with one-step silent SSH key onboarding (`remote_auth`), and exposing the read-only `mindie_doctor` readiness check across all hosts.

## Key changes and validation

- **Thin Host-Plugin Great Subtraction (`<= 1,200` LOC Hard Ceiling)**: `mindie-agent-codex v0.1.38` (`1,197` LOC), `mindie-agent-cc v0.1.30` (`1,125` LOC), `mindie-agent-kimi v0.1.31` (`1,062` LOC), `mindie-agent-dsh v0.1.26` (`1,134` LOC), `mindie-agent-agy v0.1.21` (`850` LOC), `mindie-agent-wb v0.1.19` (`1,111` LOC), and `mindie-agent-oc v0.1.11` (`1,057` LOC) delete duplicated updaters, GC, diagnostics shims, and compatibility wrappers in favor of `harness v0.1.4`, enforced permanently by `storage_lifecycle_gate.py`.
- **Zero-Git Prebuilt Wheelhouse Auto-Update & Single-Command `install.py` (Fixing `#373`)**: `mindie-bench v0.4.13` builds deterministic `< 3 MiB` `mindie-wheels-bundle.tar.gz` and `release-channel.json` assets; `harness v0.1.4` verifies `SHA256SUMS`, installs via zero-Git `--override`, and backs off (`1h -> 6h`) with `reportable=False`; top-level stdlib `install.py` auto-detects installed hosts with Receipt-Honest partial reporting.
- **`gh`-Decoupled 3-Tier Privacy, 1:1 Native Remote Profiles, Frictionless SSH & `mindie_doctor`**: `knowledge v0.13.24` adds zero-GitHub `local-only` capture/distillation (`origin_tier="local-only"`, never retroactively exported) and anonymous HTTPS corpus sync; `remote-dev v0.11.14` adds `agy`/`oc` 1:1 profiles, silent SSH key setup + NPU/container discovery (`--password` at the end for terminal paste), and `r4` password redaction; `diagnostics v0.5.17` adds read-only `mindie_doctor`; all `SKILL.md` guides codify the Non-Blocking Task Continuity rule.
