# 0.1.15: Silent Default-On Across All 7 Hosts & Zero-Binding Knowledge MCP

[中文](0.1.15.md) · [Product channel](../../channels/0.1.json)

This patch release unifies `mindie-harness` and all 7 official native host plugins around a **Silent Default-On** product model (`P2.7` / `P2.8`): removing all user-facing activation command exposure, `disable-model-invocation` skill-routing blocks, and pre-call session-binding gates on `knowledge_*`. Once a plugin is enabled, main chats, subagents, forks, and scheduled automations invoke `remote-dev`, deterministic engineering components, and `L1–L4` graded knowledge tools directly over standard zero-binding MCP while runtime `SKILL.md` loads silently on demand for Ascend tasks; background `Stop` experience capture remains strictly gated on both explicit community sharing consent (`enabled == true`) and authorized `project_roots` paths (`< 100ms` zero-SQLite fast path everywhere else).

## Key changes and validation

- **Unified zero-command Silent Default-On across `harness` and all 7 hosts**: `harness v0.1.2` plus `mindie-agent-codex v0.1.37`, `mindie-agent-cc v0.1.29`, `mindie-agent-kimi v0.1.30`, `mindie-agent-dsh v0.1.25`, `mindie-agent-agy v0.1.20`, `mindie-agent-wb v0.1.18`, and `mindie-agent-oc v0.1.10` expose `knowledge_query / explain / feedback / distill / sync` and deterministic component tools by default on startup, remove `disable-model-invocation` and manual activation ceremonies (hiding redundant slash-menu entries where supported), and work seamlessly across natural prompts and subagents.
- **Zero pre-call session-binding gates across every MCP surface (`P2.7` extended to `knowledge_*`)**: Retires `P2.1` knowledge session gating in `mindie_harness.mcp.router`, fail-closed `native_identity` in Codex, `claim_bind` in Claude Code, mandatory `request_nonce` in Kimi, `require=True` in WorkBuddy, activation gating in DSH, and manual command registration in OpenCode; every MCP surface executes over standard `tools/call` with zero `_meta` or prior `PreToolUse` nonces and auto-provisions default knowledge leases on demand.
- **Double-bounded opt-in capture & static `R4` guardrails (`P2.8`)**: Turn-end capture verifies saved sharing consent and authorized `project_roots` before touching SQLite; `zero_binding_gate.py` (`R4`) enforces static AST, `skills/`, and manifest checks across `harness` and all seven plugins.
