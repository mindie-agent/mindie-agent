## 行为变化

- **自动建立可复用的 SSH 连接**：公共 `remote_auth(action="setup")` 接收当次密码，复用既有实现安装公钥并以新进程验证。输入密码不写入配置、回执或持久环境；已有可用身份优先复用。
- **可选能力故障仅影响对应步骤**：知识、安装引导、诊断、组件和本地账本不可用时，继续可独立推进且已获授权的宿主工作。六端保留原任务目标、任务身份、权限、资源预约与活动作业。
- **MCP 单次失败保持连接**：Antigravity / WorkBuddy 的准入或记账失败返回当前请求的明确错误，后续 ping、工具目录和独立请求仍可响应。Antigravity 拒绝重放的一次性绑定，不再继承前一会话身份。
- **主结果与记账结果分别呈现**：成功的远端认证不会被本地档案保存失败改写成失败。未保存档案不会生成虚假 `auth_ref` 或被 Coordinator 登记为 ready。失败、成功与未知外部写入使用共享判定；未知写入先对账再重试。

## 验证范围

修复接受了 `gpt-6-astra / max` 两轮独立审查，确认的三项 P1 已关闭。独立隔离回归、公共 MCP 参数与分发边界、真实 stdio 连续请求和 SQLite 回执均有验证。真实 OpenSSH 验收覆盖 PowerShell、Windows PowerShell 5 与 WSL2；六端插件的最终提交另经各仓 CI 和精确发布标签的基准验证。

详细证据与审查范围见[任务连续性审计](../audits/2026-11-06-task-continuity.md)及[首次连接契约审计](../audits/2026-11-06-ssh-auth-contract.md)。本次不声称用户业务机器、NPU 推理或模型精度已经重新验收。

正式组件和插件可由既有更新器发现。组件候选准备、安装绑定切换、宿主加载新工具定义是不同状态；正在运行的宿主沿用自然重载或新进程边界，活动会话无需被强制中断。
