# 0.1.10：SSH 首次连接与任务连续性修复

[English](0.1.10.en.md) · [产品组合](../../channels/0.1.json)

本版本直接汇总已正式发布的共享组件与插件修复组合，补齐覆盖全部 15 个仓库的精确基准清单（`benchmark-manifest.json`），并将发布输入完整性校验前移至 PR CI。此前 `0.1.9` 产品候选因缺少该清单在创建正式 GitHub Release 前终止（原标签予以保留，不重指向其他提交）；本版本不重复打包无代码变更的插件，也不重新改写历史基准归档的身份标识。

在功能层面，本补丁修复了“用户已在对话中提供 SSH 密码，公开 `remote_auth` 入口却拒绝该参数并要求用户另行配置凭据”的问题，同时将“可选辅助能力故障不得阻断主线任务”的任务连续性契约统一落实到六端原生插件的引导说明与运行时错误边界中。

## 行为变化

- **一键建立可复用的 SSH 免密连接**：公开接口 `remote_auth(action="setup")` 新增一次性 `password` 入参，复用共享认证实现完成公钥自动安装并在全新子进程中验证免密登录。当次密码不会写入配置文件、回执或持久化环境变量；若本机已有可用密钥身份，则直接优先复用。
- **可选能力故障严格限定在局部步骤**：当知识检索、首次安装引导、诊断、可选组件或本地账本不可用时，Agent 继续通过已获授权的宿主原生能力推进可独立执行的研发工作，完整保留原任务目标、会话身份、权限、资源租约与在途作业。
- **单次 MCP 请求报错不中断长连接**：Google Antigravity 与 Tencent WorkBuddy 在准入或本地记账失败时仅针对当前请求返回明确错误，同一 MCP 进程后续的 `ping`、工具目录查询及独立调用仍正常响应；Antigravity 同时拒绝重放已消费的一次性 `bind`，不再跨轮次误继承旧会话身份。
- **主操作结果与本地记账状态解耦呈现**：一旦远端认证实际成功，即使本地档案落盘失败也不会被改写为认证失败（附加回执告警但保留认证成功事实）；未落盘的档案不会生成虚假 `auth_ref`，也不会被 `coordinator` 误登记为 `ready`。外部副作用统一按“成功 / 失败 / 未知（`unknown`）”共享规则分类，不确定写入必须先对账确认再决定是否重试。

## 验证范围

上述修复通过了两轮独立审查（`gpt-6-astra`，`reasoning_effort=max`），确认的 3 项 P1 问题已全部闭环。测试覆盖隔离回归、公开 MCP 参数与分发边界、真实 stdio 连续请求序列及 SQLite 回执校验；真实 OpenSSH 跨平台验收覆盖 PowerShell 7、Windows PowerShell 5.1 与 WSL2，六端插件最终提交均通过各自仓库 CI 与基于精确发布标签构建的基准校验。

详细审计证据与验证边界见[任务连续性审计](../audits/2026-11-06-task-continuity.md)与[首次连接契约审计](../audits/2026-11-06-ssh-auth-contract.md)（本补丁聚焦连接与连续性控制面，不额外声称对用户私有业务机器、NPU 推理吞吐或模型精度进行了重新实测）。

已发布的正式组件与插件可由既有自动更新器直接发现。候选运行时构建、安装绑定切换与运行中宿主加载新工具目录属于三个独立阶段；已在运行中的宿主遵循各自的自然重载或新进程边界生效，不会强制中断当前活跃会话。
