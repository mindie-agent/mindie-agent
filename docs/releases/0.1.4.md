## 知识与自动更新行为

单条和批量 graded 精读共用完整依赖闭包与最终响应预算；单条兼容字段也计入预算，预算不足时明确返回未加载状态。依赖引用来自实际修订，完整可见的同版本正文才可计入 `known_refs`。

受管组件更新覆盖独立 Python 环境中配置的标准 `python -m` 命令。候选构建遵守已安装版本下限，激活前复核并通过各端既有比较交换切换绑定；旧入口的首次升级与恢复继续保留用户命令和并发配置。Kimi 保留不可变引导依赖，通过活动覆盖层加载新组件；候选解释器的实际安装清单决定是否需要构建，源码中的目标版本不再被当成已安装版本。

“覆盖旧版”指后续调用解析到新的受管环境和命令绑定。用户知识、授权以及正在执行的任务保留；旧目录可以继续服务已加载的调用。自定义 wrapper、裸 console script、仅通过 PATH 发现的命令不被擅自接管，未安装的可选组件也不被描述为已经升级。

Codex 新增对本机实际 `0.165.0-alpha.1.2` 的精确兼容声明。此前声明未覆盖该版本，后台正确返回 `no_compatible_release`。本轮隔离无模型原生验证确认安装、五条 Hook、信任比较交换、显式禁用、SessionStart，以及 23 个远程工具和 5 个组件工具发现；相关套件 124 passed、52 subtests / 39.12s。

## 发布和安装证据

每个新组件和插件 Release 均由其标签精确源码运行合同测试与本地 CPU benchmark，随包交付校验和与报告。产品维护发布复用正式 `mindie-bench 0.4.5`，汇总十二仓正式 Release、标签 SHA、基准准入及通道清单的一致性。

四端的自动发现、候选准备、绑定切换及新原生进程加载分别记录于[自动升级验收](https://github.com/mindie-agent/mindie-agent/blob/v0.1.4/docs/releases/0.1.4/automatic-update-acceptance.json)。Claude Code 使用隔离原生 profile，本机没有全局 MindIE 插件；其他端的既有安装范围和宿主版本均在记录中说明。磁盘版本更新不单独证明已运行宿主刷新了工具或 Skill 定义。

Codex 既有可选组件命令也自动迁移：`coordinator 0.6.3 → 0.7.0`、`profiler 0.5.0 → 0.5.1`，`sim 0.7.1` 保持版本并更新解释器绑定；三条命令的实际 `--help` 执行均退出 `0`。其余端未安装的可选组件未为验收临时补装。本轮未调用模型或启动 NPU 工作负载，未强停用户会话，未手写运行时绑定。

Claude Code 的首次旧版自动迁移保留了原隔离配置，但后续加载探针遗漏原 profile 环境，新缓存入口因而按默认目录初始化了另一份配置、状态、引擎和诊断数据，影响范围不只是运行时缓存。该尝试不计为完整原生加载通过。验收保留原始记录和数据，使用完整隔离环境重新建立正式旧版并复测其注册 MCP 的自动升级路径；最终加载结论以复测为准，没有把测试环境纠正写成产品自动恢复。

## 验收中发现并修复的问题

- DSH `v0.1.8` 发布工作流被真实测试拦截：大输出超过响应预算时，仍在运行的命令被杀掉，预期业务退出码 `3` 变成 `-9`。`0.1.9` 将响应截断预算和固定 `1 MiB` 运行输出阈值分开，保留正常完成时的退出码与双流内容。旧标签和失败流水线保留，`0.1.8` 未生成正式 Release。
- Kimi `0.1.8 → 0.1.9` 的正常 launchd 更新曾把已加载的 `knowledge 0.13.6 / remote-dev 0.11.1 / diagnostics 0.5.4` 回退为引导环境的 `0.13.3 / 0.10.6 / 0.5.2`。实际包和 MCP 调度均证实了回退；插件注册版本与 `switched` 回执未能代表运行时正确。该损坏环境缺少后续更新需要的 API，不能无干预自愈，需使用现有恢复入口一次。
- `knowledge 0.13.7` 恢复旧调用方理解的引导基线契约；配套 Kimi 将活动依赖移到显式新路径，不保留会误导旧共享包的旧文件，并回读候选实际安装清单。修复后的旧版自动迁移、受损实例恢复和后续定时检查分别记录，不把一次性恢复计为原首跳全自动成功。

## 性能验收边界

此前 16 次 DSH / Codex 真实尝试保持原始结果：简单 SFA 四组配对均自然完成、CPU oracle 通过且观察到耗时和 Token 下降；Codex 存在不对称临时文件错误，净收益受环境噪声混杂。复杂任务整体不退化验收未通过，本次正式发布不将其改记为通过。

`mindie-bench 0.4.5` 保留知识统计缺测与具名调用观察下界，并修复原生 zsh 临时文件目录。修复发生在历史付费配对之后，没有重写冻结轨迹或回执。本次发布与自动升级验证不追加付费模型评测，不外推为 109 场总体收益或 A2/A3 NPU 性能结论。
