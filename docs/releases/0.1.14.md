# 0.1.14：七宿主原生触发能力对齐与运行时 `SKILL.md` 安装向导剥离

[English](0.1.14.en.md) · [产品组合](../../channels/0.1.json)

本补丁版本对全部 7 款官方原生宿主插件执行触发语义收敛与运行时 `skills/` 目录净化（`P2.8`）：按宿主原生能力区分触发方式——支持手动触发门控的六款客户端（Codex、Claude Code、Kimi Code、DSH、Tencent WorkBuddy、OpenCode）统一在 `SKILL.md` frontmatter 强制声明 `disable-model-invocation: true`（Kimi 为 `disableModelInvocation: true`）并保持 `/mindie-agent` 按会话手动唤醒；不支持手动触发门控的原子捆绑宿主 Google Antigravity（`mindie-agent-agy v0.1.19`）改为在插件启用期间默认开放全部功能（含 `knowledge_*` MCP 工具、`knowledge_cli.py` 与已开启共享授权范围内的 `Stop` 脱敏采集，未开启共享时 `Stop` 冷路径 `< 100ms`）；同时将全端插件的一次性安装引导、工作区初始化与 GitHub 认证文档（`workspace-setup.md`、`github-authentication.md`、`user-notice.md`）彻底移出 `skills/` 归口至 `docs/install/`，并在 `zero_binding_gate.py`（`R4`）建立静态防复发门禁。

## 核心变更与验证

- **`mindie-agent-agy v0.1.19` 默认开放全功能**：贴合 Google Antigravity 以插件整体为单位开关且 `SKILL.md` 语义路由无 `disable-model-invocation` 的原生机制，在 `mindie-tools` MCP 服务与 `knowledge_cli.py` 默认开放 `knowledge_query / explain / feedback / distill / sync`（支持通过 `/mindie-agent deactivate` 按会话静默关闭）；`Stop` Hook 在未开启社区共享时先走零 SQLite 冷路径直接返回 `{}`（`< 100ms`），开启社区共享且命中授权项目范围时自动完成 Brain Transcript 双层脱敏采集。
- **六款支持手动触发客户端统一加固显式禁止隐式调用门禁**：`mindie-agent-codex v0.1.36`、`mindie-agent-cc v0.1.28`、`mindie-agent-kimi v0.1.29`、`mindie-agent-dsh v0.1.24`、`mindie-agent-wb v0.1.17` 与 `mindie-agent-oc v0.1.9` 全部显式声明 `disable-model-invocation: true` / `disableModelInvocation: true`（OpenCode 同步在注入会话前自动剥离 YAML frontmatter），确保未输入 `/mindie-agent` 时零隐式唤醒。
- **运行时 `skills/` 与一次性安装文档彻底解耦（`P2.8`）**：全部 7 款宿主插件通过 `git mv` 将 `workspace-setup.md`、`github-authentication.md` 与 `user-notice.md` 迁至 `docs/install/`，清除 `SKILL.md` 与 `skills/*/references/*.md` 中所有首次安装引导、`needs_onboarding_prompt`、`vllm-ascend-workspace` 与点 Star 提示；`zero_binding_gate.py`（`R4`）对全端 `skills/` 实施静态门禁看护。
