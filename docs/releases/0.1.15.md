# 0.1.15：全七端零口令静默自启（Silent Default-On）与全表面零会话绑定

[English](0.1.15.en.md) · [产品组合](../../channels/0.1.json)

本补丁版本将全部 7 款官方原生宿主插件统一收敛为**“插件启用即全功能静默自启（Silent Default-On）”**架构（`P2.7` / `P2.8`）：彻底移除用户侧斜杠/前缀唤醒口令暴露、`disable-model-invocation` 隐式路由阻断以及 `knowledge_*` 的前置会话绑定门禁。插件启用后，主对话、子代理（Subagent）、分支会话（Fork）与定时自动化任务均可直接通过标准零绑定 MCP 调用 `remote-dev`、确定性工程组件与 `L1–L4` 分级知识检索工具，运行时 `SKILL.md` 按昇腾任务语义静默按需加载；后台 `Stop` 经验采集则严格由持久化贡献开关（`enabled == true`）与授权项目目录白名单（`project_roots`）双重约束（未开启共享或超出授权目录时走 `< 100ms` 零 SQLite 冷路径直接跳过）。

## 核心变更与验证

- **共享底座与七端插件统一零口令静默自启**：`harness v0.1.2` 与 `mindie-agent-codex v0.1.37`、`mindie-agent-cc v0.1.29`、`mindie-agent-kimi v0.1.30`、`mindie-agent-dsh v0.1.25`、`mindie-agent-agy v0.1.20`、`mindie-agent-wb v0.1.18`、`mindie-agent-oc v0.1.10` 全部默认开放 `knowledge_query / explain / feedback / distill / sync` 与确定性工程组件，移除 `disable-model-invocation` 与斜杠命令门禁（并在支持隐藏菜单项的宿主隐藏冗余斜杠入口），日常自然语言提问与子代理调用开箱即享完整知识飞轮。
- **全工具面零前置会话绑定（`P2.7` 扩展覆盖 `knowledge_*`）**：清退 `mindie_harness.mcp.router` 的 `P2.1` 知识会话拦截、Codex 强校验 `native_identity`、Claude Code `claim_bind`、Kimi 必填 `request_nonce`、WorkBuddy `require=True`、DSH 会话激活校验与 OpenCode 手动口令命令；所有表面统一在无私有 `_meta`、无前置 `PreToolUse` Nonce 的标准 MCP `tools/call` 下直通运行并按需自动补齐默认知识租约。
- **双重隐私边界与 `R4` 静态防复发门禁（`P2.8`）**：`Stop` / 会话结束采集在打开任何 SQLite 库前先核验社区共享开关与 `project_roots` 授权范围；`zero_binding_gate.py`（`R4`）对 `harness` 及全七端 MCP AST、`SKILL.md`、`openai.yaml` 与插件清单实施静态拦截看护。
