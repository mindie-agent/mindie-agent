## Known Limitations & Boundaries in `0.0.1`

- **OpenAI Codex Child-Agent Interruption**:
  - When a parent turn in OpenAI Codex CLI is interrupted while a child agent (`spawn_agent` / `wait_agent`) has an in-flight tool call, Codex may abort the child's waiting handle without delivering cancellation to the pending MCP tool call or helper subprocess, leaving a local helper/SSH process or started remote command running.
  - This host limitation is documented and accepted for `0.0.1`. MindIE Agent does not add private process-hunting watchers, arbitrary business timeouts, or custom patched Harnesses. Persistent background remote jobs remain explicitly controllable via `remote-dev` (`job_cancel`).
- **Scope Boundaries**:
  - End-to-end business quality/cost benchmarks are tracked separately; `0.0.1` makes no quantitative benchmark claims.
  - Kimi Code is outside the `0.0.1` release scope.
