[中文](0.1.17.md) · [Product channel](../../channels/0.1.json)

## Key changes and validation

- **Codex CLI `v0.1.34`–`v0.1.37 -> v0.1.39` In-Flight Session & Cross-Platform Build Hardening ([`#379`](https://github.com/mindie-agent/mindie-agent/issues/379)–[`#383`](https://github.com/mindie-agent/mindie-agent/issues/383))**: `mindie-agent-codex v0.1.39` adds thin `harness_update.py`, `runtime_call.py`, and `admission_ops.py` shims for already-open `v0.1.34`–`v0.1.37` MCP servers and `update_trigger._run` threads; stages `bootstrap.py` builds in short `%TEMP%` directories (preventing Windows `MAX_PATH` overflows), removes forced `http.sslBackend=schannel` overrides, preserves POSIX symlinked active virtualenvs without dereferencing leaf symlinks, supports `.whl` URLs in `_restore_floors`, and requires confirmed `retire_service` completion in `release_activation.py`.
- **Claude Code `v0.1.29 -> v0.1.31` Self-Upgrade & Live Frontend Handoff ([`#378`](https://github.com/mindie-agent/mindie-agent/issues/378))**: `mindie-agent-cc v0.1.31` adds floor-preserving stdlib `component_update.py`, `setup.py --source / --activate` (with `operation.lock`, `component_source_commands` CAS, and confirmed retirement), plus `bridge.py`, `mcp_server.py --once`, and `release_update.py` shims for still-open `v0.1.29` sessions.
- **Kimi Code `v0.1.30 -> v0.1.32` Probe & Committed-Tuple Launcher Handoff**: `mindie-agent-kimi v0.1.32` adds `scripts/transcript.py` for `v0.1.30` `probe_runtime`, resolves both `python` and `scripts/` together from `update/current.json` (covering both `generations/<sha>` and `component-runtimes`), and accepts legacy `updater check|status` scheduled-task invocations.
- **DeepSeek Harness `v0.1.25 -> v0.1.27` Two-Phase Handoff & Sharing Migration**: `mindie-agent-dsh v0.1.27` validates component floors during `--prepare-only`, distinguishes POSIX symlinked venvs when bootstrapping `mindie-harness-seed.pyz`, and migrates legacy `dsh/{config,mindie-consent,mindie-community}.json` into canonical paths; `storage_lifecycle_gate.py` calibrates `THIN_HOST_PLUGIN_MAX_LOC` to `1,500` lines.
