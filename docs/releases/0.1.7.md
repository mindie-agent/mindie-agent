# 0.1.7：新增腾讯 WorkBuddy 原生插件、独立 NPU 调试器 `mindie-debugger`、可配置性能建模 `mindie-sim 0.9.2` 与 9 大昇腾知识库升级

[English](https://github.com/mindie-agent/mindie-agent/blob/v0.1.7/docs/releases/0.1.7.en.md) · [产品组合](https://github.com/mindie-agent/mindie-agent/blob/v0.1.7/channels/0.1.json)

本补丁版本正式发布第六款官方原生客户端插件 **`Tencent WorkBuddy v0.1.2`**（[`mindie-agent-wb`](https://github.com/mindie-agent/mindie-agent-wb)，同时兼容腾讯 WorkBuddy 桌面端连接器与底层 CodeBuddy Agent CLI）、第八个共享运行时组件 **`mindie-debugger v0.1.0`**（[`mindie-agent/debugger`](https://github.com/mindie-agent/debugger)，将面向目标昇腾 NPU 业务负载的故障分诊、三原语精度/内存踩踏定位与 `ACLGraph` 零同步图内重放 Dump 从 Agent 自身日志上报组件 `diagnostics` 中解耦独立），发布 **`mindie-sim v0.9.2`**（支持可配置网络分层利用率、DeepEP、AFD、多级 KV/专家 Offload、公共 SKU 与自定义硬件模板）、**`mindie-profiler v0.5.6`**（实测数据反向导出 `sim` 校准包及 `xLLM`/`MindIE-SD` 支持），扩充 `knowledge-xllm` 与 `knowledge-mindie-sd` 形成 **9 大昇腾公共领域知识库**（共 `493` 个分级知识单元），并完成全部 6 大宿主插件的前向兼容区间升级与全组件锁步发版。

## 1. 第六款官方原生宿主插件：`mindie-agent-wb v0.1.2`（Tencent WorkBuddy）

1. **桌面连接器（Connector）与原生插件（Plugin）双重兼容**：
   - 同时提供 WorkBuddy 桌面端连接器规范（`plugins/mindie-agent/plugin.json` + `mcp.json`，含双语展示元数据与 `660s`/`210s` 超时预算）与底层 `@genie/agent-cli`（`codebuddy`）原生插件清单（`.codebuddy-plugin/plugin.json` + `.mcp.json` + `hooks/hooks.json`）。
2. **53 项全量 MCP 工具面与 13 项 WorkBuddy 原生远端工具镜像**：
   - 配合 `remote-dev v0.11.4` 新增的 `REMOTE_DEV_HARNESS_PROFILE=wb` 档案，除 20 项标准 `remote_*` 工具外，完整暴露 13 项 WorkBuddy 原生工具镜像（`remote_Read`、`remote_Write`、`remote_Edit`、`remote_MultiEdit`、`remote_Bash`、`remote_Glob`、`remote_Grep`、`remote_TaskOutput`、`remote_BashOutput`、`remote_NotebookEdit`、`remote_TaskStop`、`remote_KillShell`、`remote_ViewImage`），以及 `mindie-tools`（14 项，含 `debugger`）与 `mindie-knowledge`（6 项）。
3. **生命周期闭环与无感更新**：
   - 完整实现 `SessionStart`、`UserPromptSubmit`、`PreToolUse`、`Stop` 会话门控与 WorkBuddy Session Store JSONL 双层脱敏采集，并纳入 `mindie-knowledge v0.13.10` 的自动更新发现与六端前向兼容门禁（`check_auto_update_readiness.py`）。

## 2. 独立目标 NPU 调试组件：`mindie-debugger v0.1.0` 与 `diagnostics v0.5.5`

1. **职责边界清晰解耦**：
   - **`mindie-diagnostics v0.5.5`**：严格聚焦于 MindIE Agent 自身内部 DFX（本地 4×1 MiB 轮转日志、离线脱敏诊断包与带 2 次有界外发对账重试的 GitHub Issue 白名单故障上报）；
   - **`mindie-debugger v0.1.0`**（[`mindie-agent/debugger`](https://github.com/mindie-agent/debugger)）：专门面向目标昇腾 NPU 业务负载（`vllm-ascend`、`xLLM`、`MindIE-SD` 与算子工程），提供：
     - **确定性 NPU 故障分诊（`npu_fault_triage` / `decode-code`）**：支持远端容器内 CANN `plog` 自动发现、507015/507018/507035/EZ9999/HCCL 等错误码解码、进程环境变量审计与取证指引；
     - **三原语精度与内存踩踏定位（`precision`）**：`npu-watch`（张量别名图 `StorageGraph`、KV Cache 越界校验 `verify_kv_bounds`、显存观察点与环形缓冲）、`call-repro`（FP32 参照比对与非确定性抖动 vs 量化固损判定）与 `lockstep-diff`（逐层发散定位与 MoE 权重裁剪）；
     - **`ACLGraph` 静态图调试原语（`aclgraph`）**：`ACLGraphDumper`（图内无同步 D2D 拷贝与逐 Replay 步 Eager 对照）、`ACLGraphCaptureGuard`（捕获区 `.item()`/`.cpu()` 违规调用行定位）与 `ACLGraphAddressTracker`（静态输入缓冲地址漂移与 `slot_mapping` 尾部脏写拦截）。
2. **全自动更新与评测闭环**：
   - `mindie-knowledge v0.13.10` 在 `runtime_inventory.COMPONENTS` 与 `component_bindings.COMPONENT_MODULES` 中正式纳管 `mindie-debugger`，支持独立组件热升级；`mindie-bench v0.4.6` 已将 NPU 故障分诊与精度评测场景全面切换至 `mindie_debugger`。

## 3. `mindie-sim v0.9.2` 与 `mindie-profiler v0.5.6` 协同建模升级

1. **`mindie-sim v0.9.2`（可配置网络分层、DeepEP、AFD、多级 Offload 与硬件 SKU 扩展）**：
   - 支持可配置网络分层利用率、DeepEP 与 A5 MC2 通信建模、AFD（Attention-FFN Disaggregation）注意力-FFN 解耦 Pareto 求解、多级专家权重与 KV Cache（HBM / Host DDR / NVMe SSD，含 HiSparse 与 `memfabric_hybrid`）分层卸载建模、主流公共硬件 SKU 对照与自定义 SKU 模板校验。
2. **`mindie-profiler v0.5.6`（实测到仿真反向校准桥接）**：
   - 新增 `export_sim_calibration` 反向校准导出能力，可将昇腾实测 `msprof` 剖析数据一键导出为 `mindie-sim` 校准输入包，并新增对 `xLLM` 与 `MindIE-SD` 框架的剖析支持。

## 4. 9 大昇腾领域知识库、6 大宿主前向兼容与组件配套更新

1. **9 大昇腾公共知识库（`493` 个分级单元）**：
   - `mindie-knowledge v0.13.10` 与 `mindie-coordinator v0.7.3` 新增对 **`xLLM`**（[`knowledge-xllm`](https://github.com/mindie-agent/knowledge-xllm)，24 单元）与 **`MindIE-SD`**（[`knowledge-mindie-sd`](https://github.com/mindie-agent/knowledge-mindie-sd)，24 单元）的一等公民框架路由与容器镜像开通支持；[`knowledge-vllm-ascend`](https://github.com/mindie-agent/knowledge-vllm-ascend) 扩充至 93 个分级单元（新增 `runtime_guard` 与 KV 精度复合切分及中文别名检索）。
2. **6 大宿主插件前向兼容区间与全组件锁步升级**：
   - 发布 `Codex v0.1.17`、`Claude Code v0.1.13`、`Kimi Code v0.1.13`、`DSH v0.1.12`、`Google Antigravity v0.1.3` 与 `Tencent WorkBuddy v0.1.2`，将宿主版本兼容声明统一升级为支持预发布与小版本演进的前向兼容闭区间（消除宿主小版本升级导致的 `no_compatible_release` 拦截），并全量锁定上述 8 大共享运行时组件最新正式版。
