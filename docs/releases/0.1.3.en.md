## 2. Core Capabilities & Contract Boundaries

1. **Unified Three-Server MCP & Component Tool Surface Across All Four Hosts**:
   - **Per-Session Manual Gate (`knowledge`)**: Domain knowledge retrieval and distillation remain strictly gated by explicit `/mindie-agent` invocation in the active session, ensuring zero context overhead or background capture in ordinary sessions.
   - **Always-On Tools (`remote` + `components` / `mindie-tools`)**: Available by default in everyday conversation without running `/mindie-agent`, providing `remote-dev` remote Ascend development tools plus `diagnostics_status`, `diagnostics_bundle`, `coordinator`, `profiler`, and `sim` (the interactive `npu-top` dashboard remains a human terminal CLI and is not registered as an MCP tool).
   - **Timeout Arithmetic**: Outer MCP tool timeouts for `remote` and `components` / `mindie-tools` are set to `660000 ms` (11 minutes), satisfying `outer_timeout (660s) >= inner_timeout_max (600s) + cleanup_grace`.
2. **`mindie-profiler 0.5.1` Memory & Concurrency Hardening**:
   - Online evidence collection computes native shared-library (`.so`) SHA256 digests via streaming `hashlib.file_digest`, avoiding whole-file memory spikes;
   - SQLite connections configure `timeout=5.0` and `PRAGMA busy_timeout=5000`, and `except OSError:` blocks explicitly re-raise `TimeoutError`;
   - Root `mindie-profiler -h/--help` and unknown-subcommand diagnostics (exit code `2`) are standardized.
