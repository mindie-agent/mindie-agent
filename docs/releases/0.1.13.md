# 0.1.13：全栈洁净架构收敛、`mindie-harness` 公共底座抽离与 7 宿主统一对齐

[English](0.1.13.en.md) · [产品组合](../../channels/0.1.json)

本版本完成了覆盖全部 18 个代码仓库与 9 个领域知识库的系统性洁净架构重构与瘦身：正式将跨宿主共用的无窗进程与嵌套 Win32 Job 监管、确定性冷启动 Seed（`mindie-harness-seed.pyz`）、单活双代（`Active + Rollback`）`.inuse` 租约原子更新、长驻并发 MCP 网关及单状态源 `ExperimentLedger` RSI 优化闭环抽离至独立公共底座仓库 `mindie-harness v0.1.0`，让 `mindie-knowledge v0.13.23` 回归纯粹的分级知识检索、双层脱敏与社区蒸馏职责，并将第 7 个官方原生宿主插件 OpenCode（`OpenCode v0.1.8`）正式纳入产品通道统一治理。

## 架构收敛与关键验证

- **`mindie-harness v0.1.0` 独立公共宿主底座**：统一提供跨平台无窗子进程拉起与嵌套 Win32 Job 树回收、离线可校验冷启动 `mindie-harness-seed.pyz`、基于 `.inuse` 活跃租约与 `.trash/` 延迟退出的双代（`<= 2`）运行时存储生命周期治理（`P8`），以及单状态源 `ExperimentLedger` RSI 闭环引擎（`orient / propose / verdict`）。
- **确定性工具零前置会话绑定门禁（`P2.7`）与诚实回执（`P9 / P14`）**：全部 7 个原生宿主插件（`Codex v0.1.35`、`Claude Code v0.1.27`、`Kimi v0.1.28`、`DSH v0.1.23`、`Google Antigravity v0.1.18`、`Tencent WorkBuddy v0.1.16`、`OpenCode v0.1.8`）与共享组件统一遵循“标准 MCP `tools/call` 零 `_meta`、零前置 Hook、零 `request_nonce` 即可直通调用所有本地单用户确定性工具（`remote-dev`、`coordinator`、`profiler`、`sim`、`debugger`、`diagnostics`、`npu-top`）”，仅对 `knowledge_*` 保留显式会话准入（`P2.1`），对物理 NPU/端口独占保留 `HostQueue` 租约（`lease_id` + `fence_token`）；远端或组件主操作成功后若本地 SQLite 回执记账异常，严格保持 `isError=False` 并附加 `receipt_warning` 与 `receipt_unconfirmed=True`。
- **8 大领域组件与评测运行器全栈精简对齐**：`remote-dev v0.11.13`、`mindie-coordinator v0.7.13`、`mindie-profiler v0.5.16`、`mindie-sim v0.9.18`、`npu-top v0.3.5`、`mindie-diagnostics v0.5.16`、`mindie-debugger v0.1.4` 与 `mindie-bench v0.4.11` 全部完成 `< 800` 行核心模块边界、顶部 30 行四段式契约头、单次 `open_database` SQLite WAL + `busy_timeout=5000` 初始化、`outer_timeout >= sum(inner_budgets) + cleanup_grace` 超时算术及四层零宿主污染测试隔离（Tier 0–3）对齐。
- **主仓工作树路由、双语活文档瘦身与 8 类 PR 门禁**：`mindie-agent` 落地平铺同级目录 + `../.worktrees/<repo>-<topic>` 贡献路由指南、历史方案与审计报告归档（`docs/archive/`），以及覆盖 `hub / harness / host-plugin / control-plane / state-service / device-tool / bench / corpus` 的分仓画像 PR 清单与 AST 防复发门禁；9 个 `knowledge-*` 公共领域知识库同步更新至 506 个结构化分级知识单元。
- **通道资产与 `R1–R6` 发布就绪核验**：全部 17 个组件、插件与评测运行器均已通过各自跨平台 CI（Ubuntu / macOS / Windows）与源码绑定 `publish-release.yml` 正式基准门禁，发行包字节、`SHA256SUMS`、`benchmark-manifest.json` 及 `R1–R6` 自动更新就绪门禁逐项校验通过。
