# 0.1.18: Unified `mindie-harness` Substrate Consolidation, 7-Host Wire Parity & 3-Layer Zero-Mock Release Usability Gates

[中文](0.1.18.md) · [Product channel](../../channels/0.1.json)

Triggered by the post-consolidation cross-repo drift surfaced in `harness#7`, this patch release delivers a systemic fix and permanent structural prevention across the shared substrate, core runtime components, all 7 native host plugins, and the release pipeline: it consolidates MCP surface assembly and 9-domain knowledge binding into `mindie-harness v0.1.8` as the single source of truth, rolls up `profiler v0.5.17`, `sim v0.9.19`, `knowledge v0.13.25`, `remote-dev v0.11.15`, `coordinator v0.7.14`, and `mindie-bench v0.4.24`, and enforces Hub `R4` static AST anti-regression gates, the 3-OS × 7-host native wire verifier (`mindie-bench host-accept`), and pre-cutover `selftest --mode candidate` qualification so every release is end-to-end usable out of the box.

## Key changes and validation

- **`mindie-harness v0.1.8` SSOT Substrate & Pre-Cutover Selftest**: Introduces `mcp/gateway.py` (`ManagedMCPAdapter`) for exact 1:1 native surface assembly across all 7 hosts (including Antigravity's full 15-tool surface and Codex's required `session_id` on `remote_write_stdin`), `runtime/knowledge_binding.py` (provisioning 9 canonical domains with `capture_mode="disabled"` when `gitleaks` is absent so Turn-1 read-only `knowledge_query` works without `gh` or network downloads, then automatically promoting to `public-transcript` and minting an `Admission` lease on authorized `Stop`), `ProfileRef`-scoped `sharing` policy persistence, Windows concurrent cold-start `LK_NBLCK` lock retry and local prebuilt bundle staging in byte-0 `stdout`-clean `mindie-harness-seed.pyz`, and fail-closed `selftest --mode candidate|full` live MCP verification before `<host>.json` cutover.
- **Coordinated Component Hardening (`profiler v0.5.17` · `sim v0.9.19` · `knowledge v0.13.25` · `remote-dev v0.11.15` · `coordinator v0.7.14`)**: Rolls up `profiler v0.5.17` and `sim v0.9.19` (cross-repo observed/subgraph SSOT unification and CANN 9.2.1 dual-silicon calibration); `knowledge v0.13.25` supports redactor-free `capture_mode="disabled"` read-only startup, scrubs secrets from `graded:related-meta` titles before persistence, and validates PE GUI subsystem headers (`Subsystem == 2`) across both Windows venv wrappers and `pyvenv.cfg` base binaries; `remote-dev v0.11.15` extends interactive session schema overrides and reaps timed-out OpenSSH `BatchMode` children; `coordinator v0.7.14` bounds SSH `ControlMaster` exit checks with `timeout=3.0` and forced child cleanup.
- **All 7 Native Host Plugins Aligned & Legacy Edge Cases Closed**: Upgrades `mindie-agent-codex v0.1.40` (replaces bare Windows `python` launcher calls to avoid Microsoft Store App Execution Alias stubs and adopts `install.py` / prebuilt wheelhouse runtimes directly in `bootstrap.py` for zero-Git Turn-1 launch), `mindie-agent-cc v0.1.32` (converges onto `ManagedMCPAdapter` while preserving `v0.1.29` incomplete-retirement handoff status), `mindie-agent-kimi v0.1.33` (disables unsynced default feeds on cold init to prevent `FeedUnavailableError`), `mindie-agent-dsh v0.1.28` (fixes POSIX `flock` + `unlink` race in cold spool eviction and scrubs secrets before spool persistence), `mindie-agent-agy v0.1.22` (restores `remote_list_dir` and `remote_find_by_name` for full 15-tool parity), `mindie-agent-wb v0.1.20`, and `mindie-agent-oc v0.1.12`.
- **3-Layer Automated Prevention Gates (Hub `R4`/`R7` · `mindie-bench v0.4.24` · `install.py`)**: Adds `iron_rule_ast_gate.py` and `functional_smoke_gate.py`, upgrades 9-package `host_compatibility_gate.py`, manifest-level `windows_zero_popup_gate.py`, and 9-domain binding verification in `install.py`; `mindie-bench v0.4.24` ships `mindie-bench host-accept` (exercising cold byte-0 `stdout` + live `tools/call`, zero-Git `install.py`, secret-redacted `Stop` capture, and `n-1 -> n` upgrade cutover across all 7 hosts) as a mandatory 3-OS blocker on plugin PRs, single-repo releases, and the 21-cell (`3 OS × 7 hosts`) product release pipeline.
