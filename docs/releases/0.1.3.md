## 二、核心能力与契约边界

1. **四宿主统一的三路 MCP 与常驻组件工具面**：
   - **按会话手动唤醒（`knowledge`）**：领域知识检索与经验蒸馏严格受当前会话显式输入 `/mindie-agent` 门控，普通非昇腾会话零上下文污染、零后台采集。
   - **默认常驻可用（`remote` + `components` / `mindie-tools`）**：无需输入 `/mindie-agent`，日常自然语言对话可直接调用 `remote-dev` 远端昇腾开发工具集以及 `diagnostics_status`、`diagnostics_bundle`、`coordinator`、`profiler`、`sim` 五个本地诊断与分析组件入口（交互式终端看板 `npu-top` 仅供终端人工使用，不注册为 MCP 工具）。
   - **超时算术一致性**：各宿主对 `remote` 与 `components` / `mindie-tools` 的外层 MCP 工具调用超时统一配置为 `660000 ms`（11 分钟），严格满足 `outer_timeout (660s) >= inner_timeout_max (600s) + cleanup_grace`。
2. **`mindie-profiler 0.5.1` 内存与并发边界加固**：
   - 在线证据采集对大型原生共享库（`.so`）改用流式 `hashlib.file_digest` 计算 SHA256，消除整文件读入内存的峰值开销；
   - 数据库连接统一设置 `timeout=5.0` 与 `PRAGMA busy_timeout=5000`，所有 `except OSError:` 分支前置 `except TimeoutError: raise`；
   - 顶层 `mindie-profiler -h/--help` 与未知子命令（返回退出码 `2`）契约补齐。
