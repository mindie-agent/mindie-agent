# 0.1.18：`mindie-harness` 共享基座统一收敛、全七端协议对齐与三层零 Mock 发版可用性门禁

[English](0.1.18.en.md) · [产品组合](../../channels/0.1.json)

本补丁版本基于 `harness#7` 暴露的后基座收敛期跨仓漂移与首轮开箱断裂点，对共享基座、核心业务组件、全部 7 款原生宿主插件以及发版流水线进行系统性加固与防复发封堵：将 MCP 工具面组装与 9 域知识绑定统一收口至单一事实源 `mindie-harness v0.1.8`，同步升级并合入 `profiler v0.5.17`、`sim v0.9.19`、`knowledge v0.13.25`、`remote-dev v0.11.15`、`coordinator v0.7.14` 与 `mindie-bench v0.4.22`，并上线 Hub `R4` 静态 AST 反退化门禁、三平台 7 端真实协议验收器（`mindie-bench host-accept`）及客户端切流前 `selftest --mode candidate` 三道防线，确保每次发版从安装到真实 `tools/call` 与授权采集全链路开箱可用。

## 核心变更与验证

- **`mindie-harness v0.1.8` 单一事实源基座收敛与候选运行自检**：新增统一 MCP 网关组装器（`mcp/gateway.py:ManagedMCPAdapter`）精确对齐全部 7 端原生工具面（含 Antigravity `15` 个原生工具与 Codex `remote_write_stdin` 必填 `session_id`）、9 域知识绑定与安全退役编排（`runtime/knowledge_binding.py`：未配置脱敏器时以 `capture_mode="disabled"` 保证零 `gh` / 零 Gitleaks 首轮只读检索可用，授权 `Stop` 采集时按需升级为 `public-transcript` 并签发准入租约）、`ProfileRef` 归属隔离的 `sharing` 策略落盘、支持 Windows 多表面并发冷启动锁重试（`LK_NBLCK`）与本地预构建包引导的零 `stdout` 字节污染确定性种子包（`mindie-harness-seed.pyz`）以及切流前 `selftest --mode candidate|full` 实时 MCP 调用阻断门禁。
- **核心组件同步加固（`profiler v0.5.17` · `sim v0.9.19` · `knowledge v0.13.25` · `remote-dev v0.11.15` · `coordinator v0.7.14`）**：合入已独立发布的 `profiler v0.5.17` 与 `sim v0.9.19`（跨仓观测契约与闭式子图算力/访存 SSOT 统一及 CANN 9.2.1 双硅基标定）；`knowledge v0.13.25` 支持 `capture_mode="disabled"` 免脱敏器只读启动、持久化前清洗 `graded:related-meta` 标题敏感信息并在 Windows 双层校验虚拟环境启动器与 `pyvenv.cfg` 基础解释器 PE GUI 子系统（`Subsystem == 2`）；`remote-dev v0.11.15` 扩展交互式会话 Schema 回调并在 OpenSSH `BatchMode` 建连超时补齐子进程强杀清理；`coordinator v0.7.14` 为 SSH `ControlMaster` 回收补充 `timeout=3.0` 与超时强杀保护。
- **全部 7 款原生宿主插件薄化对齐与历史回归清零**：升级 `mindie-agent-codex v0.1.40`（消除 Windows 裸 `python` Microsoft Store 假桩触发，并在 `bootstrap.py` 直接领用 `install.py` / 预构建 wheelhouse 运行时以实现零 Git 首轮启动）、`mindie-agent-cc v0.1.32`（收敛至 `ManagedMCPAdapter` 并保持 `v0.1.29` 自升级不完整退役回执兼容）、`mindie-agent-kimi v0.1.33`（关闭冷启动未同步默认源以消除首轮 `FeedUnavailableError`）、`mindie-agent-dsh v0.1.28`（修复 POSIX `flock` 冷落盘池回收的持锁 `unlink` 竞态并补齐落盘池持久化前密钥脱敏）、`mindie-agent-agy v0.1.22`（补齐 `remote_list_dir` 与 `remote_find_by_name` 至完整 15 工具面）、`mindie-agent-wb v0.1.20` 与 `mindie-agent-oc v0.1.12`（收敛至共享网关并移除过期本地脚本耦合）。
- **三层自动化防复发门禁（Hub `R4`/`R7` · `mindie-bench v0.4.22` · `install.py`）**：Hub 新增 `iron_rule_ast_gate.py` 与 `functional_smoke_gate.py`，升级 9 包全量 `host_compatibility_gate.py`、清单级 `windows_zero_popup_gate.py` 及自动补齐 9 域知识绑定的 `install.py`；`mindie-bench v0.4.22` 上线通用 7 端原生协议验收器 `host-accept`（覆盖冷启动首字节纯净度与实时 `tools/call`、零 Git `install.py`、合成密钥脱敏 `Stop` 采集与 `n-1 -> n` 升级切流 4 大场景），作为单仓 CI、单仓发版与 `3 OS × 7 宿主 = 21` 格产品整包发版的强制前置阻断门禁。
