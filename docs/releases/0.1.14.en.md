# 0.1.14: Host-Capability Trigger Alignment & Clean Runtime `SKILL.md` Boundary

[中文](0.1.14.md) · [Product channel](../../channels/0.1.json)

This patch release aligns trigger semantics across all 7 official native host plugins with each host's native capabilities and purges install-time guides from runtime `skills/` directories (`P2.8`): the six hosts that natively support manual-only Skill invocation (Codex, Claude Code, Kimi Code, DSH, Tencent WorkBuddy, OpenCode) explicitly enforce `disable-model-invocation: true` (`disableModelInvocation: true` on Kimi) in `SKILL.md` frontmatter and retain manual per-session `/mindie-agent` activation, whereas Google Antigravity (`mindie-agent-agy v0.1.19`)—which enables/disables plugins as an atomic bundle with semantic `SKILL.md` routing—enables all features by default while the plugin is enabled (including `knowledge_*` MCP tools, `knowledge_cli.py`, and opt-in `Stop` capture within authorized scopes while keeping cold `Stop` `< 100ms` when sharing is disabled). Across all 7 plugins, one-time installation, workspace setup, and GitHub authentication guides (`workspace-setup.md`, `github-authentication.md`, `user-notice.md`) move out of `skills/` into `docs/install/`, guarded permanently by `zero_binding_gate.py` (`R4`).

## Key changes and validation

- **`mindie-agent-agy v0.1.19` all features enabled by default**: Matches Google Antigravity's atomic plugin toggle and semantic `SKILL.md` router by exposing `knowledge_query / explain / feedback / distill / sync` directly on `mindie-tools` MCP and `knowledge_cli.py` without requiring `/mindie-agent` (with optional per-conversation muting via `/mindie-agent deactivate`); `Stop` short-circuits before SQLite in `< 100ms` when community sharing is off and automatically captures redacted Brain transcripts within authorized scopes when sharing is enabled.
- **Explicit manual-only Skill frontmatter across all six manual-trigger hosts**: `mindie-agent-codex v0.1.36`, `mindie-agent-cc v0.1.28`, `mindie-agent-kimi v0.1.29`, `mindie-agent-dsh v0.1.24`, `mindie-agent-wb v0.1.17`, and `mindie-agent-oc v0.1.9` enforce `disable-model-invocation: true` / `disableModelInvocation: true` (with OpenCode stripping YAML frontmatter before injecting `<mindie-agent-skill>`), guaranteeing zero implicit invocation outside `/mindie-agent` sessions.
- **Clean separation between runtime `skills/` and `docs/install/` (`P2.8`)**: Moves `workspace-setup.md`, `github-authentication.md`, and `user-notice.md` into `docs/install/` across all 7 host plugins, removes all first-use onboarding, `needs_onboarding_prompt`, `vllm-ascend-workspace`, and GitHub Star prompts from `SKILL.md` and `skills/*/references/*.md`, and enforces static `R4` checks in `zero_binding_gate.py`.
