formal releases. Each host keeps its native authorization and invocation
protocol. Retrieval follows the next actionable information gap: a repair with
sufficient code, caller contracts, invariants and a verification path may use
zero knowledge calls. Exact references can be explained directly, and a query
does not require a subsequent explanation when its result is sufficient.

## Knowledge and update behavior

Single and batch graded explanations share a complete prerequisite closure and
final-response budget. Compatibility fields count toward the same budget;
insufficient space produces explicit unloaded states. Prerequisite references
use actual revisions, and only a fully visible matching body counts as a known
reference.

Managed updates include standard `python -m` component commands in independent
Python environments. Candidate builds preserve installed version floors;
activation rechecks them and uses each host's existing compare-and-swap
boundary. First upgrades and recovery preserve user commands and concurrent
configuration. Kimi retains its immutable bootstrap requirements and loads new
components through active overrides. Its candidate interpreter's actual
inventory determines whether a build is needed; declared source pins no longer
stand in for installed versions.

Replacing an old version means subsequent calls resolve to the new managed
environment and command binding. Knowledge data, consent and in-flight work
are preserved; retained old directories may serve already-loaded callers.
Custom wrappers, bare console scripts and PATH-only commands are not adopted,
and absent optional components are not reported as upgraded.

Codex adds exact support for the installed CLI 0.165.0-alpha.1.2. Earlier
declarations did not cover it and correctly reported `no_compatible_release`.
Isolated model-free native validation covers installation, five hooks, trust
compare-and-swap, explicit disable preservation, SessionStart and discovery of
23 remote tools plus five component tools. The affected suite passed 124 tests
and 52 subtests in 39.12 seconds.

from its exact tag source and ships reports and checksums. The product patch
uses formal mindie-bench 0.4.5 to verify all twelve formal releases, tag SHAs,

native process. Claude Code uses an isolated native profile;

## Defects found during acceptance

- The DSH v0.1.8 release gate caught a real output race. A running command was
  killed after exceeding its reply budget, replacing its expected business exit
  code 3 with -9. Version 0.1.9 separates reply truncation from a fixed 1 MiB
  execution-output threshold and preserves naturally completed exit codes and
  both streams. The failed workflow and old tag remain; 0.1.8 was not published
  as a formal Release.
- The normal Kimi 0.1.8 to 0.1.9 launchd update regressed the active knowledge
  0.13.6 / remote-dev 0.11.1 / diagnostics 0.5.4 combination to bootstrap
  0.13.3 / 0.10.6 / 0.5.2. Package inventory and actual MCP dispatch confirmed
  the regression despite the plugin registration and `switched` receipt.
  That damaged runtime lacks an API required by its updater and needs the
  existing recovery entry once; it cannot repair itself unattended.
- Knowledge 0.13.7 restores the bootstrap baseline contract for older callers.
  The paired Kimi fix moves active pins to an explicit new path without keeping
  the old file that confuses the older shared package, and checks the candidate
  inventory. Corrected legacy automatic migration, recovery of the damaged
  installation and subsequent scheduled checks are recorded separately.
  One-time recovery does not count as an unattended successful first hop.

## Performance acceptance boundary

The original sixteen DSH/Codex attempts remain unchanged. All four simple SFA
pairs finished naturally and passed their CPU oracle, with observed reductions
in time and tokens. Asymmetric Codex temporary-file failures confound the net
causal gain. Overall complex-task non-regression did not pass; this release does
not reclassify it as successful.

Mindie-bench 0.4.5 preserves missing knowledge measurements and named-call lower
bounds and fixes native zsh temporary-file placement. That fix followed the
paid experiment; frozen traces and receipts were not rewritten. Publication
and automatic-update checks add no paid model evaluations and make no claim
about aggregate results across 109 tasks or A2/A3 NPU performance.
