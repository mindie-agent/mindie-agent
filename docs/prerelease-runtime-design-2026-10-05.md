# 发布前运行时、复用收益与资源成本设计

状态：设计先行，隔离实现与发布前验证中；2026-10-05。承接 [知识系统设计](systematic-knowledge-design-2026-10-04.md)。没有兼容旧接口的要求。本文的验收负载、测量窗口和测试时限不是产品执行上限。

## 目标与边界

用户按原有方式做业务任务。MindIE 不增加启动口令、阶段提示、诊断入口、收尾动作或评价操作。安装时已有的贡献选择、项目范围和撤销语义继续有效；不引入第二轮授权，也不扩大到历史或其他会话。

已知错误立即失败，正常的长操作继续执行。默认没有业务执行总时限，只有用户明确要求限时才把期限交给实际执行者。watchdog 负责所有者生命周期、进程退出、管道关闭和连接健康；沉默或执行很久都不能证明失败。诊断供 Agent 使用，不投影为用户运维消息。错误必须真实保留，不能以无感为由伪造成功。

完整脱敏正文仍是可复用材料。索引和摘要仅定位，失败、纠正、条件差异和证据不确定性必须保留。去重先评估；不把相似度或引用次数变成真实性判断。

## 现有证据与设计取舍

三个独立评估方向和主任务分别检查超时/使用流程、消费者复用/去重、资源增长和远端调用。

* 同一个纯本地假 native 进程每 25 ms 输出进展，仍被 0.2 s 总时限结束；较宽时限下正常完成。收到 terminal 事件后清理超时也可能覆盖有效结果。这是生命周期与业务结果混淆的复现，不是模型速度测量。
* 远端 artifact 自有默认 120 s 总期限，Codex 包装层 65 s 先杀 helper。SSH 心跳已存在；新增更短总期限没有提供连接健康证据。
* 公开的 20 个任务、22 个块中，文件字节、正文以及空白归一化正文均没有完全重复。引用关联已经覆盖一部分复述。没有证据支持当前实施语义合并或删除。
* 两条公开查询中，默认展开相关结果使首屏 JSON 从约 24–27 KB 增至约 52 KB。组数下降不等于消费者成本下降。去掉所有相关预览又会降低纠正线索的可发现性。采用保留自身引用、摘录和必要引用状态的紧凑相关项，仍可继续展开和读取完整块。
* 六个故意包含纠正/失败/边界的反例中，现有摘要首屏只呈现 3 个关键事实，完整块可覆盖全部。这不是总体发生率，也不能把摘要可达宣称为完成业务任务的收益。
* 真实 summary idle 路径扫描已完成 material_batches；旧资源测试只覆盖另一个旧查询。warm query 重读全部 manifest 并 stat 全部块；单任务追加重复解析相同 manifest。更新器常规更新没有旧 generation 回收。

## 一次操作的生命周期

一个执行者拥有一次操作。包装层不得以自己等待了多久推断操作失败，不得重启仍在运行的操作。参数、配置、权限、依赖和已知协议错误在相应边界立即返回。取消和所有者退出传播给所拥有的本地进程树；已有远端持久 job 按现有 job 身份核对，不猜测其远端结果。

连接健康优先复用 SSH ServerAlive、进程句柄、pipe EOF、socket 错误与 native 明确错误。心跳失败阈值只判断连接失联，不能变成任务最长运行时间。连接建立也不从业务预算借用一个短倒计时；资源已满可明确拒绝，已接受的正常操作不因等待时间增长而被误判失败。

宿主要求结束一次前台等待时，返回现有操作身份并继续等待同一次操作，不能把等待窗口当成执行 TTL。已有后台 summary worker 与远端 job 机制继续承担各自职责；不另造通用任务平台。artifact 同步流保持取消与失联检测，默认无总期限；不为消除错误时限而新增常驻传输服务。

完成状态分三类：未提交、已知完成（成功或失败）、外部结果不确定。native terminal 与有效结果先落业务回执，进程/管道清理另行报告。完成后清理失败不能覆盖业务结果。已提交但没有 terminal/ACK 的模型调用或远端写入不自动重放；保留已有 intent、usage、操作身份和核对依据。

进程回收的短 join/kill 等待只作用于已决定取消或已完成的清理阶段；错误中说明回收失败。轮询间隔、调度间隔、空闲资源回收和测试 watchdog 均不属于业务期限。

## 无感接入与 Agent 内部诊断

移除日常手动 activate 前提。host 事件提供当前任务身份，命名 transcript 的可信头部提供 owner/cwd，既有贡献 choice 的 scope 与 generation 提供边界。验证后在内部按需建立归属，不扫描其他文件或会话。

采集下界来自已有授权生效时间及当前 task/fork 创建边界；不能使用首次 Stop 建立内部 binding 的时间，否则会漏掉第一轮。关停期间的内容不回填，普通任务不触发历史导入。query/explain 按需可用，不以采集激活为前置条件。

正常和失败 Hook 都不唤醒模型，不在 stdout/stderr 输出 MindIE 运维指令。失败保存到已有机器诊断通道，下次自然发生的 Agent 能力调用附带有界 incident/code/record_ref；交付后避免重复刷屏。若没有后续调用，故障保持未交付，不伪报成功。Agent 可据此诊断；用户最终答复只包含实际业务结果及与该目标直接相关的限制，不要求用户查看 MindIE 状态。

## 复用收益和去重

本次不实施语义去重、材料删除或凭摘要相似度折叠矛盾。没有完全重复样本，不为零观测收益引入正文内容寻址迁移。保留现有严格引用分组；相关项改为紧凑定位信息，保留自身 ref、feedback_ref、原文摘录、历史引用状态与独立 current_source_ref，不能把当前版本冒充旧引用。

评估分开报告：资料定位、读取成本、消费者决策正确性、错误复用、模型输入输出和等待成本。使用固定的公开/合成任务与先定义的答案规则，做同任务成对对照；处理条件变更、纠正、失败、旧版本和无可用知识。没有私人 transcript，没有主观满意度按钮，也没有每次业务的强制反馈步骤。若收益只在受控样本成立，报告该范围，不宣称普遍提升。

## 增长成本与回收

* summary 调度和预算统计查询以实际 pending/due/time 条件建立索引，完成历史不能进入每轮 idle 全扫描。
* 写事务中复用已验证的当前 header/manifest；一次追加只校验新正文，manifest 必要的整体写入仍可与块数成正比，不重复读取旧正文或多次全量 YAML 解析。
* 当前材料目录及 corpus generation 持久维护。query 读取当前目录与增量变化，warm query 不全目录扫描或 stat 所有块；变化只更新受影响块。首次打开/显式重建/恢复允许一次完整验证，损坏或缺失必须报错，不返回旧缓存伪成功。
* 派生索引增量持久化，不为一个新块重写全部原文和块对象。完整正文只保留当前有效内容，unknown outbox 等尚不能确认结果的资料不回收。
* 更新 generation 通过可达性回收：当前版本、未完成事务、仍被活跃调用或 native task 引用的版本必须保留。引用释放后自动清理工具拥有的旧环境、候选及派生缓存，不用 TTL 猜测仍在使用的版本，不触碰用户文件或无关插件。
* 维护的单轮工作预算只能产生可继续的 checkpoint/yield，不能把大语料永久标为 exhausted。必要处理继续同一次操作；完成与清理失败分别记录。

## 发布前验收

先用工作量断言检验复杂度，再记录实际耗时、CPU、峰值内存、文件读写和磁盘增长。矩阵覆盖 task 数、每 task 块数、正文大小、完成历史数量和 generation 次数；至少比较 cold、warm、单块新增、无变化 idle、重启和故障恢复。容量测试负载不是运行时拒绝阈值。

超时验收覆盖正常长时间静默/持续进展、立即失败、所有者退出、取消、断连、terminal 后清理失败及外部结果不确定；验证同一次操作只启动一次。使用流程验收覆盖无需手动激活、首轮捕获、项目范围、关停窗口、fork/兄弟任务隔离、正常/失败 Hook 无用户消息，以及 Agent 机器错误可见。

最终记录精确提交、实际测量与未验证的宿主/远端环境，按九条设计原则复查。组件测试、公开合成评估、真实 native/网络验收分别报告，不能相互冒充。正式发布前未通过的收益/容量门槛应作为明确阻塞证据，而不是用更长默认超时掩盖。

## 实施记录

核心和适配器已实现默认无总执行时限、显式取消/所有者检测、完成结果与清理失败分离、可信事件自动关联及有界 Agent 诊断。remote-dev 同时移除 artifact/RPC/SSH 各包装层默认期限；显式时限在参数入口校验，非法值在远端发送前失败。远端写入丢失 ACK 仍保留结果不确定，不能自动重放。

目录和 ReMe 派生数据改为增量 SQLite；未发布的 current/1 被 current/2 直接替换，没有旧版读写兼容路径。已有损坏或缺失目录不能重建成空库伪首次使用，当前未完成的发布不能返回成功旧缓存。源 Markdown 保留；容量改造没有做语义删除。工作量断言和实测见核心仓库的 `docs/resource-validation-2026-10-05.md`：20,000 条已完成历史的 idle/admission 从至少 80,000/120,000 VM steps 降至 18/15；128-task warm 单命中查询从 118–130 ms 降至 0.79–0.81 ms，读 manifest 为零。匹配整个语料仍有实际排序成本，单任务 manifest 写入仍随块数增长。

适配器采用稳定入口，选定 generation 与取得 OS 租约在同一配置锁内完成，调用持有租约直到结束。回收只删除工具拥有且不可达、没有活跃租约的 generation；当前、候选、事务和未明确归属的目录保留。20 个历史 generation 的隔离测试回收至当前及活跃旧版本共两个，释放旧租约后只剩当前。此结论不表示正文或有效凭据总存储固定，也不覆盖未知旧安装的原生缓存清理。

[复用评估](experience-reuse-evaluation-2026-10-05.md)已执行 12 个普通消费者和两个额外探索性对照。普通消费者均满足可见任务，但没有调用参考入口；不能把它报告为实际复用收益。强制读取正对照只证明一个未充分规定的 FP16 历史语义可从全文传递，不加入日常流程。公开样本没有严格重复块，因此暂不引入正文去重；两条紧凑预览的响应字节减少约 41%，不等于 token 或金额收益。

提交前独立审查已定位并修正目录损坏伪首次使用、跨连接未发布缓存、已确认结果被清理错误覆盖，以及卸载绕过活跃 generation 租约等问题。最终提交、测试与 CI 状态随各开发 PR 记录；旧 native 验收不覆盖此次接口。候选均已发布到 draft PR；正常 Git 安装、隔离 native 包与故障交付、真实 OpenSSH loopback 已分别验证，精确结果见[系统审查](system-review-2026-10-05.md)。没有部署或正式发布；Windows 原生 Hook/更新、真实 NPU/外部远端部署和普遍复用质量仍须分别验收。
